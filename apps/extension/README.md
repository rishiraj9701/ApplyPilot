# ApplyPilot Browser Extension (Phase 2 Placeholder)

> **Important**: This directory is reserved for Phase 2 development. Do not initialize WXT or implement extension features during Phase 1.

## Overview
ApplyPilot is a free, open-source, local-first browser extension designed to eliminate repetitive manual entry on job application forms.

## Planned Capabilities (Phase 2)
- **Local Profile Management**: Parse and store candidate profiles directly in browser storage (`chrome.storage.local`).
- **ATS Form Detection**: Recognize application forms from Greenhouse, Lever, Ashby, Workday, and custom platforms.
- **Smart Autofill**: Pre-fill standard contact, education, experience, links, and screening fields.
- **AI-Assisted Responses**: Optional integration with local Ollama or cloud providers (e.g., Google Gemini) to generate contextual answers.
- **Human-in-the-Loop Review**: No automated submission without explicit user review and confirmation.

## Phase 1 Status
Phase 1 focuses entirely on the public-facing marketing website located in `apps/website`. Development of this extension workspace will begin upon approval of Phase 1 completion.
